⚛ IoMT Research Suite — Quick Start Guide

Quantum-Enhanced IoMT Security Research | 5 Interactive Dashboards

📋 Before You Start — Requirements

  • Windows 10 or Windows 11 (any edition)
  • Python 3.10 or newer — download from python.org if not installed
  • Internet connection for first-time package installation (3–5 minutes)
  • CPU-only machine is fine — no GPU required
  • At least 2 GB free disk space for packages
Installing Python? At the Python installer screen, make sure to tick "Add Python to PATH" before clicking Install Now. If you miss this step, the launcher will not find Python.

🚀 How to Start All Dashboards

1
Extract the ZIP file to any folder on your computer (e.g. Desktop\IoMT-Suite). Do not run from inside the ZIP.
2
Inside the extracted folder, find START_HERE.bat and double-click it. If Windows asks "Do you want to allow this app to make changes?" — click Yes.
3
A black terminal window opens. On the first run, it installs Python packages — this takes 3 to 5 minutes. You will see text scrolling — this is normal. Do not close the window.
4
After packages are installed, 5 new terminal windows open (one per dashboard) and your web browser opens automatically with all 5 tabs. Wait about 15–30 seconds for all pages to load.
5
If any browser tab shows "This site can't be reached", wait 30 seconds and press F5 to refresh. The dashboard is still starting up.
From the 2nd run onwards — START_HERE.bat skips package installation and launches all dashboards in under 20 seconds.

⛔ How to Stop + Troubleshooting

S
To stop all dashboards: double-click STOP_ALL.bat in the same folder. All 5 server windows will close.
Problem Fix
Page shows "ERR_CONNECTION_REFUSED" Wait 30 seconds, press F5. Dashboard is still loading.
Black window closes immediately Python is not installed or not on PATH. Reinstall Python and tick "Add to PATH".
Hospital page is blank / loading forever First launch builds the hospital database (takes 15 seconds). Wait and refresh.
Quantum IDS shows an error after "Run Pipeline" PennyLane may still be installing. Run STOP_ALL.bat, wait 1 minute, run START_HERE.bat again.
A terminal window shows red error text Run STOP_ALL.bat then START_HERE.bat again. Usually resolves on second launch.
